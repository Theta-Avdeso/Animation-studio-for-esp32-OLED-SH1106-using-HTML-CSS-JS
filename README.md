# Animation-studio-for-esp32-OLED-SH1106-using-HTML-CSS-JS
A simple animation maker for esp32 using an oled sh1106 and HTML CSS and JS. The project ustilises the webserver library in arduino ide to create a connecrtion between esp32 and the computer allowing fast and smooth data transfer. using the HTML &lt;canvas> allows for a draing area with the characteristics of a real oled screen
